# Design Tokens Summary

| Token | Value | Usage |
|-------|-------|-------|
| `background` | `#050608` | Dark glass background on body and panels. |
| `foreground` | `#F5FBFF` | Primary text color for high contrast. |
| `primary` | `#4EF1E5` | Neon accents, CTAs, borders. |
| `secondary` | `#FF77E9` | Secondary accent for hover/focus, hero glow. |
| `muted` | `#1F2230` | Sub-surface backgrounds for cards. |
| `accent` | `#0D47A1` | Deep blue accent used in gradients. |
| `success` | `#5FFFD3` | Success state text/badges. |
| `danger` | `#FF5F87` | Error states, warnings. |
| `warning` | `#FFD166` | Connector warning states. |
| `radius.sm` | `0.375rem` | Small component corners. |
| `radius.md` | `0.75rem` | Medium radius (inputs, buttons). |
| `radius.lg` | `1.25rem` | Large panels, cards, hero surfaces. |
